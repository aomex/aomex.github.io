특징:
  - 제목: TypeScript 종단 간
    세부사항: 유형은 나중에 고려하는 것이 아닙니다. 미들웨어를 통해 ctx에 추가하는 필드는 마운트하는 순간부터 액션으로 흘러갑니다.
  - 제목: 하나의 미들웨어, 두 개의 런타임
    세부 정보: 웹 HTTP 및 콘솔 명령은 동일한 양파 모델 및 구성을 공유합니다. 비즈니스 로직을 한 번 작성하고 필요한 곳에 마운트하세요.
  - 제목: 입력 내용을 먼저 확인하세요.
    세부사항: 유효성 검사기는 ULID를 통한 문자열, Decimal을 통한 파일을 포함합니다. 전달된 데이터만 코드에 도달하고 이에 따라 유형이 좁아집니다.
  - 제목: 지연 로드 서비스
    세부 정보: CombineServices는 동적 가져오기와 프록시를 사용합니다. 요청 시 초기화되며, 메소드는 항상 Promises를 반환하고 종료 시 onDestroy를 반환합니다.
  - 제목 : 배터리가 포함된 생태계
    세부 정보: 인증, 캐시, 로깅, 속도 제한, 압축, CORS, Cron, OpenAPI / Swagger / Redoc 등 필요한 것을 설치하세요.
  - 제목: 노드 ≥ 24
    세부 정보: 내장된 압축, 보다 안정적인 파일 및 네트워크 API, 레거시 수하물 감소 등 런타임에 가깝게 유지됩니다.
