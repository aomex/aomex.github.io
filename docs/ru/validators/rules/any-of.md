# rule.anyOf()

**Должна пройти хотя бы одна** ветка; несколько совпадений по-прежнему успешны (логин: адрес электронной почты или идентификатор сотрудника; поиск `q`: UUID или пул).

Для общих методов цепочки см. [Общие цепочки](../chain); ниже — только **специфичные для rule** API.

```typescript
import { rule, schema } from '@aomex/common';

export const loginSchema = schema({
  account: rule.anyOf([ // [!code highlight]
    rule.email(),
    rule.string().match(/^@[a-z0-9_-]+$/i),
  ]).required(),
});
```

- Подразумевается как **объединение** типов ветвей — шире, чем один `string`.
- Нет цепочки, специфичной для правил; связывайте каждое подправило отдельно.
- Вам нужно **ровно одно** совпадение? Используйте [oneOf](./one-of) — перекрытие не удается `oneOf`, но обычно все равно проходит `anyOf`.

Для общих цепочек см. [Общие цепочки](../chain); см. также [oneOf](./one-of), [allOf](./all-of), [email](./email), [string](./string).
