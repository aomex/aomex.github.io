# rule.boolean()

Приводит ввод, подобный переключателю, к **логическому значению**: флаги публикации, `?featured=1`, JSON `isAdmin`.

Для общих методов цепочки см. [Общие цепочки](../chain); ниже — только **специфичные для rule** API.

```typescript
import { rule, schema } from '@aomex/common';

export const listQuery = schema({
  published: rule.boolean().default(false), // [!code highlight]
});
// ?published=1 → true；省略 → false
```

- После проверки выводится как `boolean`.
- Истинные/ложные литералы по умолчанию (например, `'true'`, `1`) сопоставляются с логическими значениями; после настройки списков передаются только перечисленные значения.
- При использовании `default(false)` поле по-прежнему печатается как `boolean`, даже если оно отсутствует.

Правдивость по умолчанию: `1` / `'1'` / `true` / `'true'`; ложь: `0` / `'0'` / `false` / `'false'`. Пользовательский интерфейс с тремя состояниями (не установлено/да/нет) не должен принудительно переводиться в `boolean` — используйте `optional()` или отдельное поле перечисления.

### setTruthyValues(values: any[])

**Заменяет** список правдивости по умолчанию (не добавляется).

**Когда использовать:** устаревшие системы или HTML-формы отправляют `yes`/`on`/`Y` вместо `true`.

```typescript
import { rule } from '@aomex/common';

rule.boolean().setTruthyValues(['yes', 'on', 'Y', 1, true]);
// 'on' → true；覆盖后默认的 'true' 可能不再认
```

Изменение только `setTruthyValues` без обновления ложных значений может привести к тому, что переключатели застрянут во включенном состоянии или промежуточные состояния вернут 400.

### setFalsyValues(values: any[])

**Заменяет** ложный список по умолчанию.

**Когда использовать:** сочетание со списком правдивости, когда клиент отправляет `no`/`off` для выключения.

```typescript
import { rule } from '@aomex/common';

rule.boolean()
  .setTruthyValues(['yes', 'on', 1, true])
  .setFalsyValues(['no', 'off', 0, false]);
```

Значения вне обоих списков не работают; `strict()` нет — герметичность полностью зависит от ваших списков.

Для общих цепочек см. [Общие цепочки](../chain); поля с несколькими состояниями см. [enum](./enum); переключатели обычного текста см. [string](./string).
