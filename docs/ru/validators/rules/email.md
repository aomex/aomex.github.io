# rule.email()

Проверяет **строки в форме электронного письма**: регистрацию, получателей уведомлений, приглашения (только формат, а не наличие почтового ящика).

Для общих методов цепочки см. [Общие цепочки](../chain); ниже — только **специфичные для rule** API.

```typescript
import { rule, schema } from '@aomex/common';

export const registerSchema = schema({
  email: rule.email().required(), // [!code highlight]
});
// { email: 'ada@example.com' } → 通过；'ada@' → 失败
```

- Выводится как `string`; OpenAPI часто отмечает `format: email`.
- Нет специальной цепи обрезки/длины — управляйте с помощью [Общие цепочки](../chain) `transform` или в действии.

Используйте эту фабрику для любого поля «должен быть адрес электронной почты»; не имитируйте его с помощью `string().match`. Логин «электронная почта или идентификатор сотрудника» соответствует [anyOf](./any-of).

### match(pattern: RegExp)

**Когда использовать:** только для домена корпоративной регистрации, суффиксы белого списка бета-версии (после прохождения базового формата электронной почты).

```typescript
import { rule } from '@aomex/common';

rule.email().match(/@acme\.com$/i);
// 'ada@acme.com' → 通过；'ada@gmail.com' → 格式过、match 失败
```

`match` добавляет только ограничения формата — он не заменяет логику «проверочное письмо отправлено» в вашем приложении.

Для общих цепочек см. [Общие цепочки](../chain); см. также [string](./string), [url](./url), [anyOf](./any-of).
