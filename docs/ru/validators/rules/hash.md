# rule.hash()

Проверяет **форму шестнадцатеричной хэш-строки** (фиксированная длина для каждого алгоритма): `contentMd5`, `etag`, `sha256` отпечатки пальцев (только формат, без вычисления хеша).

Для общих методов цепочки см. [Общие цепочки](../chain); ниже — только **специфичные для rule** API.

```typescript
import { rule, schema } from '@aomex/common';

export const callbackSchema = schema({
  contentMd5: rule.hash('md5').required(), // [!code highlight]
});
// 'd41d8cd98f00b204e9800998ecf8427e' → 通过
```

- После проверки выводится как `string`.
- Алгоритм выбирается только на заводе: `md5`/`sha1`/`sha256`/`sha512` и т.д.; Префиксы `0x` или Base64 обычно не работают.

Выберите алгоритм с фабричным аргументом, например. `rule.hash('sha256')`; неизвестные алгоритмы следуют подсказкам типов и ошибкам времени выполнения.

Для общих цепочек см. [Общие цепочки](../chain); подобные формы: [string](./string), [buffer](./buffer), [file](./file).
