# rule.ip()

Проверяет **IP-литералы**: список разрешенных `clientIp`, узлы VPN, адреса преобразователей (выберите `v4` / `v6` на заводе).

Для общих методов цепочки см. [Общие цепочки](../chain); ниже — только **специфичные для rule** API.

```typescript
import { rule, schema } from '@aomex/common';

export const allowlistSchema = schema({
  peer: rule.ip('v4').required(), // [!code highlight]
});
// '203.0.113.10' → 通过；'2001:db8::1' 在只 v4 时 → 失败
```

- После проверки выводится как `string`.
- **Версия только на заводе** `rule.ip('v4' | 'v6' | [...])`; помощника цепи `.v6()` нет.

### match(pattern: RegExp)

**Когда использовать:** после того, как значение является действительным IP-адресом, заблокируйте очевидные закрытые диапазоны (сложный CIDR принадлежит действию с выделенной библиотекой).

```typescript
import { rule } from '@aomex/common';

rule.ip('v4').match(/^10\./);
// '10.0.0.1' → 通过；'203.0.113.1' → 失败
```

Для общих цепочек см. [Общие цепочки](../chain); см. также [string](./string), [url](./url), [hash](./hash).
