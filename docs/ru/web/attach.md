# Загрузка файлов

Создайте составной интерфейс с аватаром или вложением: отметьте поле файла как [rule.file()](/ru/validators/rules/file) в body(), получите временный путь и MD5 из ctx.body после прохождения теста и переместите его до окончания этого раунда запросов (либо OSS, либо локальное хранилище). Multipart без body() не поможет вам проанализировать файл.

```typescript
import { rule } from '@aomex/common';
import { body, Router } from '@aomex/web';

export const router = new Router();

router.post('/users', { // [!code focus:13]
  mount: [
    body({ // [!code highlight]
      name: rule.string(),
      avatar: rule.file(),
    }),
  ],
  action: async (ctx) => {
    const { name, avatar } = ctx.body;
    await saveAvatarToOss(avatar.filepath, avatar.hash);
    ctx.send(201, { name, hash: avatar.hash });
  },
});
```

Клиент использует multipart/form-data: имя — общее поле, а аватар — часть файла. Распространенный подход заключается в немедленной загрузке или копировании в действии, а затем возврате — временный файл будет очищен после завершения ответа.

После прохождения проверки аватара есть примерно путь к файлу, размер, тип mime, хеш, алгоритм хэша и исходное имя файла; путь к файлу и хэш чаще всего используются в бизнесе. ` rule.array(rule.file())`когда ctx.body.attachments представляет собой массив файловых объектов.

::: warning
Файл не был перемещен или загружен до возврата 201, и не гарантируется, что временный путь будет доступен для чтения в следующем раунде.
:::

## Громкость и MIME

одно поле ` rule.file().maxSize()`/`.mimeTypes()` На **фазе проверки** блокировка слишком больших или неправильных загрузок экономит один цикл ввода-вывода по сравнению с вводом действия и последующим выполнением загрузки. и уровень приложения `formData` При укладке выбирайте более строгую сторону; если вы меняете только маршрутизацию, не забудьте прочитать 413 с обеих сторон.

```typescript
body({
  avatar: rule.file().maxSize('2mb'),
});
```

```typescript
body({
  avatar: rule.file().mimeTypes('.png', 'image/*'),
});
```

` rule.file().maxSize('2mb')`Только сузьте это поле; при сочетании с formData.maxFileSize уровня приложения, кто более строгий?

Вернитесь к MIME, если магическое число нестабильно:

```typescript
rule.file().mimeTypes('image/svg+xml').fallbackToMimetype(),
```

::: warning
Не используйте FallbackToMimetype() для аватаров общедоступной сети — доверяйте Content-Type, сообщаемому клиентом. Он подходит только для контролируемых сценариев, таких как интрасети.
:::

## Одно и то же поле в нескольких файлах

Входные данные с тем же именем в форме HTML могут передавать несколько частей. ` rule.array(rule.file())`Соберите их в массив. использовать `.length({ max: n })` Ограничьте количество отдельных запросов, чтобы избежать одновременной загрузки слишком большого количества больших файлов.

```typescript
body({
  attachments: rule.array(rule.file().maxSize('10mb')).length({ max: 5 }),
});
```

Если в одном запросе имеется несколько полей файлов, на общее число также будет распространяться ограничение formData.maxFiles уровня приложения, которое будет более строгим вместе с квотой уровня маршрутизации.

## Квоты с помощью WebApp.formData

Анализ файлов разделен на два уровня: **WebApp.body.formData**. Установите значение по умолчанию для всего сайта (один том файла, общее количество частей), в маршрутизации. ` rule.file()`Затем сузьте поле. Когда после изменения только одного слоя появляется 413, проверьте, не блокируют ли его правила приложения или поля.

| слой | Как использовать его обычным способом |
| --- | --- |
| ` WebApp.body.formData ` | Верхний предел по умолчанию для всего сайта. Для больших файловых сайтов сначала настройте здесь. |
| ` body()`+ схема | Анализируйте только поля, указанные в схеме. |
| ` rule.file()` | Бизнес-правила с одним полем (MIME, том) |

```typescript
new WebApp({
  services,
  logger: services.logger,
  language: { mode: 'fixed', language: 'zh-CN' },
  proxyIP: { mode: 'detect' },
  body: { // [!code focus:3]
    formData: { maxFileSize: '20mb', maxFiles: 10 }, // [!code highlight]
  },
  mount: [routers('./src/routers')],
});
```

Большие файлы помещаются во временный каталог на диске, а не сохраняются в памяти, что упрощает их потоковую передачу в объектное хранилище. Если в маршруте изменяется только maxSize, не забудьте проверить formData уровня приложения. 413 необходимо проверить на обоих уровнях.

вложенные объекты ` rule.file()` Часто оно не соответствует именам плоских полей multipart. Сложные конструкции нужно сначала выровнять и как передать их клиенту.

::: warning
Нераспознанные токены в mimeTypes сообщат об ошибке на этапе настройки, что устраняет необходимость автоматического освобождения всех типов.
:::
